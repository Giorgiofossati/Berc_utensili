## Anatomia osservata (24/25)
- **Contenitore**: `w-[96vw] … max-w-4xl lg:max-w-5xl xl:max-w-6xl … !max-w-6xl` → di fatto **1152px fissi** (l'`!important` annulla la scala responsive). Raggio `28/36/40px`, `max-h-[92dvh]`. È la modale più larga dell'app dopo il picker distinta (Tier 4), pur essendo un form.
- **Header** (h ≈ 115px): box icona 48px `rounded-2xl` senza bordo + overline ciano "NUOVO INSERIMENTO" + `app-h2` "AGGIUNGI ARTICOLO" + X **tonda** 40/48px a destra. Nessun sottotitolo.
- **Corpo**: due "card" grigie numerate `1`/`2` (`rounded-3xl bg-slate-950/5`) → dentro la 1: 4 select + accordion grigio più scuro (`rounded-2xl bg-slate-950/5`) → dentro ogni campo un ulteriore wrapper grigio (`p-2 rounded-2xl border`) → input. **Tre livelli di scatola** prima di arrivare al controllo.
- **Campi**: 13 select `Seleziona …` visivamente identici (4 principali + 9 avanzati), 3 input testo, 1 number, 1 select stato. 12 label con `*`, 1 con "(Opzionale)", 2 senza indicazione.
- **Footer** (h ≈ 100px, sfondo `bg-black/5`): un solo bottone "SALVA ARTICOLO" **verde** `.action-btn-carica` a destra. Nessun "Annulla".
- **Mobile (64)**: colonna singola, ogni campo ≈ 100px di altezza; header 170px + footer 150px consumano ~40% del viewport; il corpo scorre per ~1900px.

## Regole mancanti nel design system

### §5.E Form (da riscrivere: oggi ha 3 righe)
1. **Componente `FormField`** obbligatorio: `label` (`.app-label`, nuovo token), controllo, `hint`, `error` (`app-caption text-accent-rose`, `aria-describedby`), stato `aria-invalid`. Vietato replicare wrapper a mano.
2. **Griglia**: Tier 2 → `grid-cols-1 sm:grid-cols-2`; Tier 3 → `… lg:grid-cols-3`; mai 4 colonne in un form; `gap-4`; textarea e campi identificativi `col-span-full` quando serve.
3. **Gruppi**: max 6-7 campi per gruppo (Miller); titolo gruppo `.app-h3` + `border-t`, senza sfondo; numeri solo in un vero stepper con navigazione. Ordine canonico: Identificazione → Classificazione → Dettagli → Gestione.
4. **Obbligatorietà**: un'unica fonte (schema) alimenta label e validazione; se gli obbligatori sono la maggioranza si marcano gli opzionali "(opzionale)", altrimenti gli obbligatori con `*` + legenda; mai entrambe le convenzioni nello stesso form.
5. **Disclosure progressiva**: un accordion chiuso di default può contenere solo campi opzionali; badge calcolato "N campi · M compilati"; apertura automatica se un campo dentro diventa pertinente o ha errori.
6. **Errori**: inline sotto il campo + riepilogo nel footer + focus sul primo errore + scroll/apertura sezione; `alert()` e bubble nativi vietati; errori server → toast `NOTIFICA SISTEMA`.
7. **Placeholder**: solo esempi di formato ("es. …"), mai la label; unità di misura come suffisso fuori dal campo.
8. **Campo codice/barcode**: componente `BarcodeInput` (mono + camera 44px + supporto lettore HID + unicità live) usato ovunque si inserisca un codice.
9. **Campi condizionali**: se la visibilità dipende da un altro campo, il campo nascosto non è mai obbligatorio e il valore viene azzerato con un avviso, mai in silenzio.
10. **Dirty-form guard**: chiusura con dati compilati → conferma Tier 1.
11. **Stato success** delle form di creazione: card con riepilogo + "Aggiungi un altro" + "Chiudi"; nessun auto-close.

### §5.D Modali
1. **Scala larghezze**: aggiungere la regola "i form usano Tier 2 o Tier 3, mai Tier 4"; vietare `!max-w-*`. Eventualmente Tier 3 rinominato "Form esteso / Dettaglio tecnico".
2. **Componenti `ModalHeader` e `ModalFooter`** al posto della prosa di §5.D.4: header = icona 48px con bordo + overline + titolo + sottotitolo opzionale + X 44px `rounded-2xl`; footer = sinistra (stato/errore) + destra (Annulla terziario + Primaria).
3. **Colore della primaria per tipo**: Salva/Conferma = `.action-btn-primary` (blu); Carico = emerald; Scarico = rose; Ordine = orange; Distruttiva = rose solo in Tier 1. Il verde non è "OK", è "Deposita".
4. **Stato disabled** della primaria finché i campi chiave sono vuoti (come Commesse).
5. **Comportamento sotto `sm`**: sheet full-screen, header compatto 56px, footer sticky con primaria full-width `min-h-[52px]`.
6. **Raggio unico** `rounded-[28px] sm:rounded-[32px]` e z-index da token (`--z-modal`, `--z-popover`).
7. Correggere §5.D: `dialog.jsx` è **Base UI**, non Radix.

### §3 Tipografia
- Token **`.app-label`** (11-12px, bold, tracking ridotto) per etichette form; `.app-overline` resta per micro-titoli di sezione.
